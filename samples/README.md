# Data contoh

Seluruh payload dalam folder ini bersifat sintetis. Nama supplier, laboratorium,
verifier, sekolah, perangkat, lokasi, waktu, dan nilai sensor tidak mewakili
operasi Program MBG yang sebenarnya.

Urutan penggunaan:

1. `batch.json`
2. `telemetry.json`
3. `nutrition.json`
4. `delivery.json`
5. panggil endpoint evaluasi dan trace

Data contoh tidak memuat identitas siswa, orang tua, koordinat rinci, atau
kredensial.
